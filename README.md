# 브랜드 이미지 레퍼런스 라이브러리

회사 공식 웹사이트가 공개한 이미지 중 디자이너가 참고하기 좋은 자산을 회사와 업종별로 정리한 정적 웹 라이브러리입니다.

## 현재 수집 현황

- 회사: 275개
- 고유 이미지 파일: 1,130개
- 파비콘: 269개
- 소셜 대표 이미지: 155개
- 로고 분류: 219개
- 배너 분류: 150개
- 기타 참고 이미지 분류: 357개
- 전체 이미지 용량: 약 73MB

한 이미지가 배너와 기타 참고 이미지 양쪽에 해당하면 파일은 한 번만 저장하고 분류 정보만 공유합니다.

## 웹에서 할 수 있는 일

- 회사명과 페이지 키워드 검색
- 업종별 필터
- 배너, 로고, 소셜, 기타 참고, 파비콘 유형별 필터
- 배너와 로고 수집 여부별 필터
- 이미지 수, 회사명, 업종 기준 정렬
- 회사별 전체 이미지 모달 보기
- 해상도, 파일 형식, 용량 확인
- 이미지 파일 저장과 원본 출처 확인
- 라이트 모드와 다크 모드 전환

## 파일 구조

```text
assets/업종/회사-slug/
  favicon.*
  og.*
  logo-1.*
  logo-2.*
  banner-1.webp
  banner-2.webp
  reference-1.*
  source.json

index.html
app.css
app.js
manifest.json
manifest.csv
reference_collector.py
```

`manifest.json`과 회사별 `source.json`에는 이미지 유형, 저장 경로, 원본 URL, 해상도, 용량, 파일 형식과 해시가 기록됩니다.

## 로컬에서 보기

파일 요청을 사용하는 웹 페이지이므로 폴더에서 간단한 웹 서버를 실행한 뒤 접속합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173/`을 엽니다.

## 다시 수집하기

```powershell
python reference_collector.py --workers 12
```

특정 회사만 다시 수집하려면 회사명이나 slug를 지정합니다.

```powershell
python reference_collector.py --company 현대자동차
python reference_collector.py --company hyundai-motor
```

## 수집 기준

- 로고: 구조화 데이터, 헤더, 내비게이션, 파일명과 대체 텍스트를 기준으로 선별
- 배너: 메인 비주얼, 히어로, 프로모션, 캠페인 영역과 이미지 비율을 기준으로 선별
- 기타 참고: 공식 사이트 첫 화면의 제품, 서비스, 콘텐츠 이미지 중 충분한 해상도를 가진 항목 선별
- 배너와 참고 이미지는 최대 1800px WebP로 최적화
- SVG 로고와 투명 배경 로고는 가능한 원형을 유지

공식 사이트가 자동 접근을 차단하거나 첫 HTML 응답에 이미지를 포함하지 않는 경우 새 이미지가 비어 있을 수 있습니다. 이런 회사도 기존 파비콘과 소셜 대표 이미지는 유지하며, 웹 화면에서 미수집 상태를 확인할 수 있습니다.

## 출처와 사용 범위

모든 이미지의 권리는 각 회사와 원저작권자에게 있습니다. 이 저장소는 디자인 조사와 레퍼런스 확인을 위한 자료 모음이며, 상업적 재사용 전에는 각 출처의 이용 조건과 브랜드 가이드를 확인해야 합니다.
