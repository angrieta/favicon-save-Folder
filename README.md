# 브랜드 레퍼런스 라이브러리

국내외 유명 회사 공식 웹사이트의 레이아웃, 헤더·푸터·카드·섹션 같은 화면 구성 요소, 버튼, 로고, 배너, 아이콘, 포인트 컬러를 회사와 업종별로 모은 정적 웹 라이브러리입니다.

## 현재 수집 현황

<!-- stats:start -->
수집을 마친 뒤 `python library_stats.py`로 갱신합니다.
<!-- stats:end -->

같은 그림은 한 번만 보입니다. 완전히 같은 파일, 같은 회사 안에서 거의 같은 캡처(지각 해시), 최신 캡처와 첫 화면이 같은 예전 캡처는 정리 단계에서 빠집니다.

## 웹에서 할 수 있는 일

**보기**
- 이미지: 모든 자료를 한 화면에 펼쳐 보는 기본 보기, 썸네일 크기 S·M·L·XL
- 회사별: 회사 카드, 포인트 컬러, 회사별 전체 자료 모음
- 컬러: 회사마다 사이트에서 실제로 쓰는 메인·보조·포인트 컬러와 무채색. 색상 계열(빨강, 파랑 등)로 거르고 HEX를 눌러 복사
- 보관함: 찜한 이미지와 직접 만든 보드

**유형과 구성**
- 유형 탭: 레이아웃, 버튼, 배너, 로고, 메뉴·버튼 아이콘, 소셜 공유, 사진·콘텐츠, 그래픽, 앱 아이콘, 파비콘
- 레이아웃을 고르면 구성으로 다시 나눠 봄: 전체 페이지, 첫 화면, 헤더, 네비게이션(GNB, 메가메뉴, 모바일 햄버거 메뉴, 전체 메뉴), 섹션, 카드, 푸터, 플로팅(퀵메뉴, TOP 버튼, 챗봇, 하단 고정 바, 쿠키 배너), 팝업, 검색·폼, 탭
- 버튼을 고르면 스타일(채움·라인)과 모양(알약형·둥근 모서리·각진 모서리)으로 나눠 봄. 크게 보기에서 배경색, 글자색, 테두리, 모서리, 높이, 글자 크기를 확인하고 CSS로 복사

**필터**
- 업종 목록(여러 개 함께 선택), 지역(국내·해외), 기기(PC·모바일), 색상, 톤, 비율, 최소 가로 해상도, 파일 형식, 지난 버전 포함
- 검색: 회사명, 초성(ㄹㄷ), 영문 slug, 버튼 글자, 아이콘 용도. HEX 코드(예: `#FF5A1F`)를 넣으면 그 색과 가까운 자료를 찾음
- 정렬: 추천, 최근 캠페인, 해상도, 회사명, 무작위
- 필터 상태가 주소에 저장되어 새로고침하거나 링크를 공유해도 같은 화면이 열림

**크게 보기**
- ←/→ 이동, 체크·흰색·검정 배경, 원본 크기 보기
- 구성 요소는 전체 페이지 캡처 원본에서 해당 영역만 선명하게 보여 줌
- 대표 색상 팔레트, 회사 포인트 컬러, 같은 색으로 이미지 찾기
- 같은 회사 이미지, 비슷한 이미지(지각 해시·색감), 변천사(지난 버전)
- 이미지를 클립보드에 복사해 Figma에 바로 붙여넣기, 파일 저장, 출처 정보 복사

**모으기와 내보내기**
- 하트(찜)와 여러 개의 보드
- 여러 장 선택(Shift+클릭으로 범위 선택) 후 찜, 보드 추가, 나란히 비교(최대 6개), ZIP 저장, 출처 복사
- ZIP에는 `출처.csv`가 함께 들어감
- 동기화 코드로 다른 컴퓨터에서도 같은 찜 목록과 보드 사용

단축키는 화면 오른쪽 위 키보드 버튼에서 확인할 수 있습니다.

## 파일 구조

```text
assets/업종/회사-slug/          파비콘, OG, 로고, 배너, 참고 이미지 (reference_collector.py, add_companies.py)
layouts/업종/회사-slug/         전체 페이지 캡처 (날짜별)
  2026-09-29-pc.webp
  2026-09-29-mobile.webp
components/업종/회사-slug/      따로 찍은 구성 요소: 팝업, 플로팅, 열린 메뉴, 버튼(2배), 아이콘(3배)
thumbs/                         이미지 벽용 작은 썸네일 (build_library.py)
icons/업종/회사-slug/           예전 방식으로 모은 메뉴·버튼 아이콘
history/업종/회사-slug/         교체된 배너·로고·소셜 이미지

index.html, app.css, app.js     웹 화면
manifest.json, manifest.csv     회사 목록과 이미지 자산
components.json                 수집기가 남긴 구성 요소 원본 기록 (영역 좌표, 버튼 스타일, 사이트 색상)
layouts.json                    전체 페이지 캡처 목록
parts.json                      웹 화면이 읽는 정리된 구성 요소와 캡처 목록 (build_library.py가 생성)
brand_colors.json               회사별 포인트 컬러
analysis.json                   이미지별 대표 색상, 밝기, 채도, 투명 배경, 그래픽 여부
icons.json, history.json
```

헤더, 첫 화면, 섹션, 카드, 푸터, 검색·폼, 탭은 전체 페이지 캡처 위의 좌표로만 저장합니다. 같은 픽셀을 두 번 저장하지 않아 용량이 작고, 크게 보기에서는 원본 캡처에서 그 영역을 바로 잘라 보여 줍니다. 팝업, 플로팅, 열린 메뉴처럼 전체 캡처에 나오지 않는 상태만 따로 찍습니다.

## 회사 추가와 수집

1. 회사 추가 (`company`, `slug`, `url`, `category`, `sub`, `region` 목록 JSON). 파비콘과 OG 이미지를 함께 받습니다.

   ```powershell
   python add_companies.py new_companies.json
   ```

2. 로고, 배너, 참고 이미지 (공식 사이트 첫 화면 HTML 기준)

   ```powershell
   python reference_collector.py --slugs-file slugs.txt --workers 12
   ```

3. 화면 구성 요소, 버튼, 아이콘, 사이트 색상 (설치된 Chrome 또는 Edge, Node.js 22 이상)

   ```powershell
   node collect_components.mjs --workers 6 --skip-existing
   node collect_components.mjs --company 롯데렌터카 --devices pc
   ```

   한 번 방문할 때 로드 팝업을 찍고 숨긴 뒤, 스크롤하며 지연 이미지와 플로팅 요소를 찍고, 화면 단위로 이어 붙인 전체 페이지를 저장합니다. 스크롤 연출이 있는 사이트도 실제 보이는 화면대로 남고, fullPage.js처럼 한 화면씩 넘어가는 사이트는 화면을 차례로 넘기며 찍습니다. PC에서는 메가메뉴(마우스 오버)와 전체 메뉴를, 모바일에서는 햄버거 메뉴를 열어 찍습니다.

4. 정리 (썸네일, 빈 캡처와 중복 제거, 포인트 컬러) 후 색상 분석

   ```powershell
   python build_library.py
   python analyze_assets.py
   python build_library.py --skip-assets
   ```

   수집기는 `components.json`과 `layouts.json`만, 정리 단계는 `parts.json`과 `brand_colors.json`만 씁니다. 그래서 수집 중에도 정리 단계를 돌릴 수 있습니다.

그 밖의 도구: `deep_reference_collector.py`(내부 페이지까지 심층 수집), `capture_layouts.mjs`(전체 페이지만 캡처), `collect_icons.mjs`와 `clean_icons.py`(아이콘만 수집·정리), `optimize_assets.py`(무손실 용량 줄이기), `library_stats.py`(수집 현황).

## 포인트 컬러를 정하는 방법

브라우저로 사이트를 열어 CSS 변수(`--primary`, `--brand`, `--point` 등), `theme-color`, 채움 버튼의 배경색, 강조 글자색, 넓은 유채색 배경, 링크 색을 모으고, 로고와 파비콘의 색을 더합니다. 비슷한 색은 묶고, 여러 근거에서 함께 나온 색에 가중치를 줍니다. 가장 강한 유채색이 메인, 충분히 다른 다음 색이 보조와 포인트가 됩니다. 근거가 CSS 변수 하나뿐이면(프레임워크 기본색일 가능성) 무채색 브랜드로 봅니다.

## 용량

- 전체 페이지는 WebP 품질 60, 따로 찍는 구성 요소는 품질 62, 버튼은 2배 크기에 품질 80
- 헤더·섹션·카드 등은 파일 없이 좌표로만 저장
- 이미지 벽은 가로 480px 이하 썸네일(`thumbs/`)을 먼저 불러오고, 크게 볼 때만 원본을 읽음
- OG 이미지는 가로 1200px 이하 WebP로 변환

## 출처와 사용 범위

모든 이미지의 권리는 각 회사와 원저작권자에게 있습니다. 이 저장소는 디자인 조사와 레퍼런스 확인을 위한 자료 모음이며, 상업적 재사용 전에는 각 출처의 이용 조건과 브랜드 가이드를 확인해야 합니다.
